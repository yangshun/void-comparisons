# Void vs. the major metaframeworks: feature gap analysis

A comparison of **Void** with Next.js, React Router, TanStack Start, Nuxt, SvelteKit, SolidStart and Astro across 14 areas, down to individual props and options, to find Void's feature gaps and inform its roadmap. Prepared 2026-11-04.

**Read it at https://yangshun.github.io/void-comparisons/**. The site includes a filterable explorer of every gap.
